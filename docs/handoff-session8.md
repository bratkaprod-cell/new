## Технические нюансы

- Вход в Яндекс: код приходит push в Яндекс Браузер или СМС — просить у владельца в чат.
- Веб-интерфейс Директа быстрее Коммандера для добавления фраз: окно «Ключевые фразы» принимает
  список по одной фразе в строке; минус-слова кампании — Настройки кампании → Дополнительные
  настройки → «Минус-фразы» (текстовое поле, по одному слову в строке). Кириллицу вставлять из
  буфера обмена (`Set-Clipboard` из UTF-8 файла), не печатать.
- Кнопку «Запустить кампанию» на странице настроек НЕ нажимать; сохранять только «Сохранить изменения».
- Редактор ЕПК (`/dna/banners-edit?...&banners-ids=<id>`): поля — `contenteditable` с placeholder
  «Добавьте N из 7/3» (пробелы Unicode — искать регэкспом `/Добавьте\s*2\s*из\s*7/`); заполнять
  через `focus()` + `execCommand('selectAll')` + `execCommand('insertText')`, следующее поле
  появляется после перерендера. Уточнения: кликнуть в поле после последнего чипа, набрать текст и
  нажать реальный Enter (синтетический keydown не фиксирует). Лимиты: заголовок 56, текст 81,
  уточнение 25.
- Директ Коммандер установлен (OAuth). Выгрузка кабинета — UTF-16 TSV с двумя служебными строками
  перед заголовком; колонки английские (`Campaign name`, `Group name`,
  `Phrase (with negative keywords)`, `Negative keywords for campaign`).
- Последняя выгрузка до правок сессии 8: `docs/direct-live-export.csv` (43 + 50 фраз, 81 минус).
  После завершения п. 1–2 нужно выгрузить заново и заменить файл.
- Сайт: `python build.py` для сборки, локально `python -m http.server 8000`.
