# Аудит семантики и минус-слов — кампании IntelPrime (сессия 8)

Источник: выгрузка Коммандера `docs/direct-live-export.csv` (43 фразы «Горячие», 50 фраз «CMS»,
81 минус-слово на уровне каждой кампании, одинаковый список в обеих) + частотности
`docs/wordstat-data*.json`. Кампании № 714043997 и № 714044004 — черновики, изменения в кабинет
НЕ вносились, только рекомендации.

## Итог одной строкой

Ядро собрано грамотно (нет пустых высокочастотников вроде «безопасность сайта», есть
операторы `-!как`, `-плагин`), но есть **3 дыры, которые сольют бюджет в первую неделю**, и
~25 недостающих «горячих» фраз владельца сайта.

## 1. Критично — исправить до запуска

### 1.1 Фраза «лечение сайтов» (группа «Лечение сайтов (услуга)») — главный слив
Директ матчит по словоформам, поэтому фраза `лечение сайтов` покажет объявление по запросам:

| Запрос | Частота/мес | Закрыт минусом? |
|---|---|---|
| лечение официальный сайт | 21 107 | **нет** |
| сайт санатория лечение | 16 791 | да (`санаторий`) |
| сайт санаторно курортного лечения | 1 046 | **нет** |
| сайт пансионата с лечением | 387 | **нет** |
| сайт лечение суставов / позвоночника | 183 / 181 | **нет** |
| лечение сайта казань | 224 | целевой — ок |

Что делать (любой вариант):
- заменить `лечение сайтов` на `лечение сайтов от вирусов`, `лечение сайта от вредоносного кода`,
  `лечение сайтов услуга`, `лечение !сайтов -официальный -санаторно -курортный` (оператор `!`
  фиксирует форму «сайтов», медицина ищет «сайт»);
- и обязательно добавить минусы из п. 3.

Та же проблема (слабее) у `лечение сайта цена` и `лечение сайтов москва`: «лечение … официальный
сайт цены» — добавить `-официальный`.

### 1.2 Пользовательские (не владельческие) запросы в группе «Вирус на сайте»
`антивирус блокирует сайт`, `браузер блокирует сайт вирус`, `сайт помечен как вредоносный`,
`сайт редиректит на другой сайт` — в 80–90 % случаев это посетитель, у которого Касперский/Chrome
ругается на чужой сайт, а не владелец. Оставить только с уточнением владельца:
`мой сайт блокирует антивирус`, `сайт помечен как вредоносный что делать владельцу`,
`яндекс пометил мой сайт как опасный`, или перенести в отдельную группу с пониженной ставкой и
смотреть поисковые запросы через 3 дня. Остальные — отключить.

### 1.3 Несогласованные операторы в CMS-кампании
`взлом wordpress -!как -самостоятельно`, `взлом битрикс -!как`, `взлом joomla -!как` — правильно,
а `взлом opencart` и `взлом modx` идут без `-!как` → покажутся по «как взломать opencart».
Добавить `-!как -самостоятельно` к обоим.

## 2. Недостающие горячие фразы (добавить)

### Кампания «Горячие» (взлом и вирусы)
Симптомы, которые ищет владелец (высокая конверсия, конкурентов мало):
- `сайт перекидывает на другой сайт`, `сайт перебрасывает на другой сайт` (синонимы «редиректит»)
- `на сайте появилась чужая реклама`, `на сайте появились чужие ссылки`
- `сайт рассылает спам`, `с сайта идет спам рассылка`
- `хостинг заблокировал сайт вредоносный код`, `хостер заблокировал сайт за вирус`
- `яндекс вебмастер угрозы безопасности`, `вебмастер нашел вредоносный код`
- `сайт может нанести вред компьютеру гугл`, `сайт содержит вредоносное по что делать`
- `сайт в черном списке яндекса`, `убрать сайт из черного списка`
- `удалить дорвей с сайта`, `удалить шелл с сайта`, `удалить бэкдор с сайта`
- `дефейс сайта восстановить`, `восстановление сайта из бэкапа`
- `сайт заражен -!как -!такое` (543/мес, сейчас есть только «…вирусом что делать»)
- `проверка сайта на вредоносный код`, `проверить сайт на взлом` (уточнить группу «Защита и аудит»)
- `удаление вирусов с сайта срочно`, `лечение сайта срочно`, `лечение сайтов спб`
- Конкурентные бренды (опционально, отдельная группа): `virusdie`, `revisium`, `айри антивирус`

### Кампания «CMS»
- WordPress: `wordpress вредоносный код удалить`, `wp вирус редирект`, `wordpress сайт перекидывает`,
  `wordpress взломали восстановить`, `wordpress malware удалить`
- Bitrix: `1с битрикс вирус лечение`, `битрикс проактивная защита взлом`, `bitrix вредоносный код`
- Joomla: `joomla взломали восстановить`, `joomla вредоносный код`
- OpenCart: `opencart взломали что делать`, `opencart вредоносный код`, `ocstore взлом`
- MODX: `modx взломали что делать`, `modx evo вирус`, `modx revo вирус`
- PHP: `php шелл удалить`, `eval base64 decode удалить с сайта`, `php сайт рассылает спам`

## 4. Структурные рекомендации директолога

1. **Кросс-минусовка** между группами не нужна (стратегия автоматическая, дубли Директ склеил), но
   между кампаниями стоит: в «Горячие» добавить `-wordpress -битрикс -bitrix -joomla -opencart -modx`,
   чтобы CMS-запросы шли в профильные объявления с релевантным заголовком (выше CTR/ниже CPC).
2. **Автотаргетинг «только целевые запросы»** при минимальном бюджете лучше выключить на первую
   неделю: с 43 фразами и 1 500 ₽/нед он съест 30–50 % бюджета на околоцелевые.
3. Через 2–3 дня — отчёт «Поисковые запросы» (Статистика → Мастер отчётов → срез «Поисковый
   запрос»), всё с «официальный», «санатор», «скачать», «как» — в минусы кампании.
4. Оператор `!` на «сайт/сайта/сайтов» стоит поставить только там, где форма меняет смысл
   («лечение сайтов» vs «лечение … сайт»). Кавычки не использовать — трафика мало.
5. Ставки: при «Максимум кликов» с недельным бюджетом ставки не задаются; лимит CPC 120 ₽ оставлен —
   для ниши (реальный CPC 60–250 ₽ по горячим) можно поднять до 180 ₽ после первых 50 кликов.
