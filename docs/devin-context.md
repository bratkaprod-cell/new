## Что планировалось дальше (задача пользователя)

Своя CMS для этого сайта уровня Textolite: редактирование текста, изображений, ссылок, цветов любых
элементов (кнопки, текст, фон), контактов/номеров, соцсетей, возможно порядка блоков — без правки
исходного кода вручную. Оценка: ~1–2 сессии работы. Предполагаемая архитектура: админка с логином,
визуальное редактирование, загрузка картинок, настройки цветов, хранение контента в JSON и интеграция
с существующим `build.py` (либо PHP-рантайм, т.к. хостинг Apache + `.htaccess`).
